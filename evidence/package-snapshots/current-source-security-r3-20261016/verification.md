# Контрольная сборка security r3 — 16 октября 2026

Версия 0.8.18, локальный unsigned NSIS. Это отдельный проверочный каталог `.verification/current-source-security-r3-20261016`, а не опубликованный релиз. На текущем Windows 11 выполнены следующие проверки:

- Совпадение всех 277 собранных ресурсов и Arduino CLI с исходной production-сборкой; настройки Electron fuses; запуск и отказ второго экземпляра; намеренное повреждение ASAR отклонено, исходный архив точно восстановлен.
- В фактическом EXE проверены собственная панель окна, мотивация при запуске, компактное чтение и локальная озвучка, масштаб кода, иллюстрации, RU/KK-названия, чат, поиск по 55 проектам и отсутствие ошибок страницы. Чат обращался только к локальной тестовой заглушке; два запроса, платного провайдера не было.
- Настоящий минимальный справочный ESP32 compile через Arduino CLI завершился exit 0 и дал шесть артефактов. Путь содержал кириллицу и пробелы. После перезапуска восстановлен сохранённый код, EXE и ASAR не менялись. Полный compile-цикл занял **374169 мс**; это остаётся проблемой скорости. SDK использован из обычной ранее подготовленной копии, физической платы не было.
- Microsoft Defender: отдельное custom-сканирование каталога сборки с `-DisableRemediation`, exit 0 и сообщение об отсутствии угроз. Хеши EXE/ASAR/Setup до и после совпали. Это результат одного сканирования с текущими базами.
