# 0.8.5 — Blocks, C++ and independent study

This development build retains the Studio changes documented in [0.8.4](RELEASE-0.8.4.md): collapsible icon navigation, an explicit USB board-run dialog, saved-program activity calendar, twelve simulator fields and student chat without provider/model controls. Redundant Studio heading instructions are removed. The board-run command uses the real compiler and guarded uploader; unavailable hardware support is reported rather than simulated as successful upload.

L37 is now registered in the curriculum with substantial English, Russian and Kazakh theory, a generated-source walkthrough, an animated diagram, a five-item checked mapping activity, adaptive hints, durable answers, two knowledge checks and an exported mapping report. Its sample demonstrates includes, serial initialization, setup once and repeated loop statements. The displayed source and line numbers come from the actual generator. They describe the teaching sample; a different project/profile can produce different lines.

The task leads learners through preserving their blocks, creating an independent Code copy, editing a message and delay, checking a missing-semicolon error and saving the copy separately. Mapping answers certify only the mapping exercise. Exported reports explicitly record compilation/upload/physical execution as not performed by that exercise. Actual builds and physical observations are separate evidence.

The student manual now explains current editor layouts, independent projects, local learning progress and optional assistant code sharing in all three languages. It uses separate paragraphs and appropriate reference labels. Lesson actions stay in normal page flow so they do not cover practice while scrolling. Shared exercise presentation is separated into `LearningExercise`; validated learning records and strict backup keys now support L37 without changing the existing database table count or version.
