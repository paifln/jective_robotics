# L21 steering comparison groundwork

The working tree adds three actual RobotSimulation programs: equal 20/20 commands, unequal 10/20 commands and opposite −20/20 commands. Each runs for one second, commands stop, waits for ramp-down and exports the complete trace with its program, geometry, units and modeled polarity signs. The comparison uses an open world with a shared central start, 0.18 m track, 0.6 m/s maximum model speed and 1.25 m/s² acceleration. Commands are percentages of that model maximum, not measured physical duty or velocity.

Guide G04 exposes a trilingual comparison panel. Equal commands produce a straight trajectory; unequal commands curve toward increasing y with positive heading; opposite commands rotate in place. The SVG explicitly uses y upward and marks final heading, so rotation remains visible even when the position path is stationary. Model left-polarity reversal changes the equal-command run into rotation; restoring its sign produces the straight result again. Exports preserve each run's signs instead of claiming hardware calibration.

The native Electron scenario runs the original, reversed and corrected comparisons, reads the three downloaded trace bundles and verifies their distinct signs/outcomes. Domain tests check straight/curved/in-place outcomes, completed stop, no collision, corrected polarity and rejected malformed cases. Current evidence is under evidence/differential-steering; it is source-build verification only.

L21 is now registered as an authored EN/KK/RU draft lesson with 785 learner-facing English words, three explained assessment questions, checked concept/numeric practice, starter/reference block projects and the shared open-world scenario. Learners export the three comparison paths, preserve polarity mismatch/correction reports and independently edit the starter for an in-place rotation. A four-point rubric evaluates classification, units/axes, correction evidence and trace-supported prediction. The Electron test also loads both lesson projects into Studio and verifies their straight/curved worker outcomes.

Curriculum is now 21/60; 39 lessons and technical translation review remain. No physical motor polarity, assembly geometry, wheel slip, upload or trajectory measurement is validated here.
