# L28 two-sensor line following: source scope

The current source contains 28/60 authored draft lessons. Content validation counts 833 learner-facing English words. Published 0.8.1 installer and source ZIP remain unchanged at 23 lessons; this increment is unpackaged.

Geometry is part of the decision table: the stripe is 0.03 m wide and probe spacing 0.02 m. Both dark means centered (20/20), left dark means left correction (10/20), right dark means right correction (20/10), and both light requests a latched stop. The default 0.05 m probe spacing would invalidate this centered interpretation. The lesson explicitly tests that counterexample instead of silently replacing the geometry assumption.

The standalone controller additionally handles missing, nonfinite, out-of-range and calibration-gap readings, manual stop, timestamp ordering and late updates. A late-update fault is observed when the next tick arrives, not an independent watchdog. The block program uses the actual simulator's binary reflectance; it does not claim noisy physical measurements or arbitrary external input equivalence. Manual stop is checked every 20 ms and remains latched after release. Line loss requests zero immediately; actual wheel settling in these fixtures takes at most 100 ms. A finite 8-second program window ends with a stop and settling wait. The starter deliberately treats loss as centered and travels farther than the reference.

Seven targeted tests cover the table, turn direction, uncertainty, stop latches, malformed clocks, actual geometry, 400 decisions in each of four real simulation traces, and a scheduled manual-stop priority test. Initial acceleration gives both wheels equal increments even with unequal commands; the incorrect initial test assumption is retained under evidence/line-following/initial-acceleration-test-failure.json and corrected to inspect wheel asymmetry after acceleration.
