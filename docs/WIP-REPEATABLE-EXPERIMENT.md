The comparison service executes two supported block algorithms through the real RobotSimulation engine. The algorithms differ only in stopping threshold (0.4 versus 0.7 m). Both use the same wall, robot configuration, initial pose, speed and 20 ms wait/physics step. Each runs twice with the selected seed and once with a comparison seed. Work is bounded to 300 steps per trace; seeds are unsigned 32-bit integers and noise is 0–0.2 m.

The report contains the exact world/program snapshots, labelled units and raw states. Same-seed equality compares complete state traces rather than only the final pose. Different seeds can change noisy sensor values; this is observed, not guaranteed. Zero-noise and equal-seed controls explicitly report unchanged traces. No arbitrary C++, compiler or physical device is invoked.
