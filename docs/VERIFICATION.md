# Результаты проверок

## 16 октября 2026 — текущая работа

Последний чистый снимок r9 прошёл 633 доменных теста в 206 файлах и 133 выбранных GUI-сценария в 131 файле, без пропусков, ошибок и нестабильных повторов; все 1091 входной файл неизменны. Ветви packages — 96,29%, прежний порог 80% на файл сохранён. Прошли статические, серверные, аудио- и build-проверки; отдельно повторены пять текущих GUI-сценариев. EXE r5 и неподписанный установщик проверены на целостность, интерфейс и Defender. Настоящие успешная/ошибочная компиляции с проверкой исходника/результатов и восстановлением прошли; одиночный повтор по пути с кириллицей — 323563 мс. Это не полная приёмка продукта. [Точный вечерний журнал](../evidence/evening-20261016/verification.md), [снимок](../evidence/evening-20261016/source-r9.json), [компилятор](../evidence/evening-20261016/compiler-r5.json).

В неизменном снимке r6 прошли **616 доменных тестов в 204 файлах и 132 GUI-сценария в 130 файлах**. Ветви packages — 96.32%, порог 80% для каждого файла сохранён. Прогон GUI консервативный: исключены 28 файлов compile/toolchain/upload, кроме диалога импорта без запуска инструментов. Это не полный прогон интерфейса и не независимый `npm ci`.

В текущем рабочем дереве дополнительно прошли 19 серверных Node-тестов на Windows и в Linux-контейнере без сети, Windows PowerShell-мастер с явно тестовым ключом и публичный Linux-сценарий проверки Docker. Новый CI-job и Dependabot подготовлены, GitHub Actions не запускались.

[Контрольный пакет security r3](../evidence/package-snapshots/current-source-security-r3-20261016/verification.md) прошёл проверку ресурсов, fuses, отказа при порче ASAR, фактического интерфейса, настоящего минимального compile и восстановления после перезапуска. Compile-цикл 374169 мс остаётся проблемой скорости. Defender не обнаружил угроз в пакете и Setup; хеши не изменились. EXE/Setup не подписаны, установщик не запускался.

[Утренний журнал и ограничения](../evidence/security-hardening-20261016/verification.md), [передача проекта](HANDOFF.md), [Railway](../services/assistant/deploy/railway/README_RU.md). Контейнер Railway развёрнут, семь настоящих HTTPS-сценариев прошли; вечером получен один настоящий ответ OpenAI. Облачная квота после перезапуска, Windows 10, установка/обновление/удаление и физическая плата не проверены.

После снимка r6 добавлен [Jexi](../evidence/jexi-20261016/verification.md): отдельно прошли 4 UI-сценария, 11 клиентских и 19 серверных тестов, проверка фактического нового EXE с двумя локальными тестовыми запросами. Это не повторение полной батареи r6 на новых исходниках. Новый контейнерный прогон с именем Jexi прошёл на Linux без сети, включая сброс привилегий, хранилище и квоту после перезапуска; все созданные им контейнеры/тома/образ и временная папка удалены.

Не подтверждены: Windows 10, полный цикл установки/обновления/удаления, готовность текущего релиза, публичный HTTPS-сервер помощника, реальный аккаунт/модель OpenAI и работа физического набора. Набор JECTIVE ещё не изготовлен.

Следующие ручные проверки перечислены в [плане приёмки](RELEASE_ACCEPTANCE_RU.md). Отдельная задача по скорости: минимальный compile-цикл r5 занял 306 765 мс с полным хешированием SDK; это не готовый целевой результат для школьного компьютера.

Полные локальные трассы, снимки и повторяющиеся отчёты исключены из Git; текстовые итоги и выбранные файлы матрицы сохранены. Их отсутствие на GitHub не меняет результат на «успешно». Матрица требований проверяет структуру ссылок, а не выполнение требований.
