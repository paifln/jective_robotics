# Результаты проверок

Промежуточное состояние на 15 октября 2026 года. Результаты относятся к указанным сценариям и исходникам; не означают полной готовности продукта.

| Проверка | Результат |
| --- | --- |
| Доменные тесты | 580 тестов, 192 файла — прошли в отдельном чистом экспорте без SDK; 96,33% ветвей packages, порог 80% на файл сохранён |
| Сервер помощника | 14 тестов на локальных HTTP/upstream-заглушках — прошли |
| Границы архитектуры | 2 теста — прошли; скрытые системные импорты отклонены |
| TypeScript, ESLint, сборка | Прошли |
| Аудит зависимостей | 0 известных уязвимостей в проверенном дереве |
| Узкая студия | Прошёл отдельный сценарий размеров окна, трёх языков и контраста |
| Полный прогон интерфейса | Первый: 69 прошли, 82 не прошли, 1 пропущен, 2 ошибки runner. Второй неизменный снимок: 147 прошли, 7 не прошли, 2 пропущены, 0 ошибок runner. Исправленные сценарии прошли отдельно; новый полный текущий прогон не заявляется |
| Заставка | Фраза с логотипом, смена при перезагрузке, отсутствие карточки в уроках и начисления активности — прошли отдельную проверку Electron |
| Вёрстка каталога мотивации | 59 фраз × 3 языка × 2 размера (800×640 и 1280×800): 354 сочетания без выхода за границы; последовательная подстановка текста с текущими Electron-стилями, не 354 настоящих запуска |
| Ошибки USB-инструментов | Некорректный ответ IPC и исключение открытия монитора: безопасное сообщение, сброс недоступного порта, повторная попытка — прошли на заглушках |
| Размер кода | Ctrl+/−, Ctrl+0 и Ctrl+колесо: изменение шрифта без изменения исходника, активности и масштаба окна — отдельный Electron-сценарий прошёл |
| Упакованная r5 | Startup/fuses/277 ресурсов/tamper, UI и настоящий минимальный compile + restart — прошли; установка и физическая плата не проверены |

Свидетельства: [чистый production-экспорт без SDK](../evidence/clean-source-20261015/verification.md), [многофайловые проекты с настоящим компилятором](../evidence/native-multifile-20261015/verification.md), [сервер и архитектура](../evidence/assistant-architecture-security-20261014.md), [область кода в студии](../evidence/studio-code-space-20261014.md), [первый baseline](../evidence/full-ui-baseline-20261015/verification.md), [второй полный прогон с ошибками](../evidence/full-ui-second-20261015/verification.md), [упакованный снимок r5](../evidence/package-snapshots/current-source-windows-shell-r5-20261015/verification.md).

Отдельные прежние EXE проверялись на текущем Windows 11, в том числе компиляция минимального справочного ESP32-проекта. Результаты привязаны к хешам тех сборок; их нельзя автоматически переносить на последующие исходники или установщики.

Не подтверждены: Windows 10, полный цикл установки/обновления/удаления, готовность текущего релиза, публичный HTTPS-сервер помощника, реальный аккаунт/модель OpenAI и работа физического набора. Набор JECTIVE ещё не изготовлен.

Следующие ручные проверки перечислены в [плане приёмки](RELEASE_ACCEPTANCE_RU.md). Отдельная задача по скорости: минимальный compile-цикл r5 занял 306 765 мс с полным хешированием SDK; это не готовый целевой результат для школьного компьютера.

Полные локальные трассы, снимки и повторяющиеся отчёты исключены из Git; текстовые итоги и выбранные файлы матрицы сохранены. Их отсутствие на GitHub не меняет результат на «успешно». Матрица требований проверяет структуру ссылок, а не выполнение требований.
