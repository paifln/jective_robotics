# Rover inspection foundation for L19

The working tree now validates a versioned G04 inspection report containing the chosen board definition, assembly revision, either supported motor-driver configuration, its logical wiring map, six inspection items and an optional teacher observation with a dated note. Missing or failed inspection items remain incomplete. Unknown fields and invalid timestamps are rejected. Wiring review uses the existing board capability, reserved-pin, conflict and provisional-profile checks.

Learner-entered checks alone never create physical evidence. An observer record is recorded evidence, not independent authentication. Even a complete report never declares hardware readiness: electrical ratings, carrier identity, motor behavior and actual physical safety are outside this report. No serial port, upload or motor action is triggered.

The report now belongs to the project's validated worksheets and survives portable archives, SQLite autosave and reconstructed backups. G04, the two-wheel rover guide, exposes a trilingual inspection form with driver selection, logical GPIO mapping, six observed checks, explicit project storage and JSON export. An empty observation remains unrecorded; no teacher identity is invented by the form. A stored board definition records the report's chosen profile snapshot independently of later project edits.

L19 is now registered as an authored draft worksheet lesson in EN/KK/RU, with 763 learner-facing English words, three explained assessment questions, checked practice, an independent driver-map comparison and a four-point evidence rubric. Its project-owned inspection form is accessible both from the lesson and G04. Curriculum is now 19/60; 41 lessons remain, translations need technical educator review and physical inspection has not been performed here. The published 0.7.0 artifacts do not contain these changes. Earlier evidence/rover-inspection snapshots cover the foundation; current lesson proof is under evidence/L19.
