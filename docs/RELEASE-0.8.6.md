Under Studio project settings, **Work on a project copy** creates a deeply independent project in the same editor mode. Copy invariants reject changed source, workspace, profile, wiring, mode and metadata. Duplicate insertion failure rolls back all changes. The current external save path is cleared only after successful duplication, so editing and saving the copy cannot silently overwrite the original file. The command does not compile, open a port or upload firmware.

`divisionObservation` is a bounded teaching model for whole inputs from -10000 to 10000 and nonzero divisors. It compares integer division, conversion before division, conversion after division and a Boolean predicate. The local counter model contrasts recreated locals with file-lifetime state. These results are not an interpreter for arbitrary C++ and not physical execution. Checked predictions persist in validated local learning records and backups; exploratory observations remain in the current laboratory session and can be exported (at most twenty rows). Reports explicitly mark compiler/upload/physical verification as not performed by the model. Code projects must be saved separately.
