# Мотивация при запуске

Короткая мысль показывается только на синем экране запуска с белым логотипом. Приветствий по времени суток и мотивационной карточки внутри уроков нет. Каталог встроен в приложение: интернет, ключ API и генерация ИИ во время запуска не нужны. Открытие приложения не добавляет учебную активность.

В начальном каталоге 59 разных записей: 9 коротких цитат с источниками и 50 авторских фраз JECTIVE. Каждая доступна на русском, казахском и английском. Это не тысяча проверенных цитат. Каталог можно расширять без изменения интерфейса; повторы и выдуманные атрибуции для количества не добавляются.

При каждом запуске выбирается запись, отличная от предыдущей. Локально хранится только идентификатор последней записи. Если хранилище недоступно, заставка продолжает работать. Время загрузки ради чтения цитаты дополнительно не увеличивается. Переводы цитат помечены; ссылка на источник доступна в подсказке при наведении.

Проверено по доступным первичным институциональным публикациям 15 октября 2026. Русские и казахские формулировки — редакционные переводы, не оригинальная речь авторов. Профессиональная языковая вычитка казахского текста ещё требуется. Имена авторов не подразумевают их поддержку продукта.

Небольшой `launch-entry.ts` загружается раньше основного интерфейса и редактора. Основной модуль использует уже выбранную фразу, поэтому во время одного запуска цитата не меняется. Отдельная Electron-проверка фиксирует появление фразы и логотипа до заполнения основного окна. Дополнительное время ожидания не добавлено.

Реализация: `packages/engagement/launch-motivation.ts`, `apps/desktop/renderer/launch-screen.ts`, `apps/desktop/renderer/launch-entry.ts`. Проверки: уникальность и локализация каталога, ограничение случайного выбора, отсутствие немедленного повтора; реальный Electron: фраза вместе с логотипом, смена при перезапуске, отсутствие карточки в уроке и начисления активности. Эти проверки не заменяют оценку мотивационного эффекта учениками.

Дополнительно проверена геометрия всех 59 записей на трёх языках при 800×640 и 1280×800: 354 сочетания без выхода логотипа, фразы и подписи за границы. Для этой проверки текст последовательно подставлялся в отдельную заставку с текущими compiled Electron-стилями после обычного запуска. Это проверка вёрстки, а не 354 настоящих запуска, оценка времени чтения или проверка всех вариантов системного масштаба. Локальный результат: `.verification/launch-catalog-layout-20261015.json`.
