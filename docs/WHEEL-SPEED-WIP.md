The dedicated forward-only bench uses a declared first-order wheel with nominal maximum 0.6 m/s and time constant 0.25 s. Exact plant integration advances every 20 ms; count feedback is sampled every 100 ms. The shared encoder configuration controls both count generation and conversion, including an alternate-resolution API/test. Instantaneous model speed and interval-averaged, quantized encoder estimate remain separate exported fields. This is not a spatial RobotSimulation load extension or physical speed acquisition.

Feedforward converts the 0.18 m/s request to 30 percent. Gain times requested-minus-estimated speed is clipped to ±30 percentage points, and final output to 0–60 percent. Zero gain provides a comparison without speed correction but retains diagnostic feedback checks. The first raw sample supplies no speed: output stays zero until a valid elapsed interval provides measured zero. Missing/reset feedback, a late observed update or stop request latches a stop/fault. Feedback recovery does not rearm motion.

Load factor 0.55 applies between 2 and 4 seconds. Default loaded mean absolute estimated-speed error during 3–4 seconds is 0.080556 m/s without correction and 0.035000 m/s with gain 400. Residual error remains. Normal stop is requested at 6000 ms; sampled model speed falls below 0.001 m/s at 7300 ms. This threshold is not exact zero or physical braking certification. Feedback loss at 3000 ms preserves missing estimates, restores a correctly calculated 600 ms measurement window at 3500 ms and leaves output stopped. Graph curves split across null estimates; an optional dotted curve reveals model truth.
