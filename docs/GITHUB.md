# Подготовка к публикации в GitHub

README описывает запуск, возможности, структуру, сервер и фактический статус проекта. Исходники, `package-lock.json`, необходимые учебные ресурсы и тесты входят в репозиторий. Открытая лицензия не назначена: текущий статус — `UNLICENSED`.

## Что исключено

- `node_modules`, `dist`, `release`, `.toolchain`, `.verification`, `test-results`, `coverage`.
- Реальные `.env`, зашифрованные секреты, мастер-ключи, сертификаты с ключами, токены и ученические базы.
- Большие локальные скриншоты, трассы и повторяющиеся отчёты `evidence`.
- Личные настройки IDE и временные системные файлы.

Шаблоны `*.env.example` остаются в Git. Текстовые свидетельства и точные ссылки `docs/requirements.json` разрешены отдельными правилами `.gitignore`. При добавлении новой ссылки на машинный отчёт обновите это правило; иначе проверка ссылок на чистой копии обнаружит отсутствие файла.

`.gitignore` не удаляет файлы с диска и не исключает уже отслеживаемые файлы из истории Git. Проверка известных форматов секретов также не гарантирует отсутствие любой чувствительной информации: просмотрите содержимое коммита перед публикацией.

## Перед коммитом

```powershell
git status --short
npm run github:check
git diff --check
```

После просмотра изменений:

```powershell
git add .
git diff --cached --stat
git diff --cached --check
git commit -m "Prepare JECTIVE Robotics Studio source and documentation"
git push
```

Команды коммита и пуша выполняются владельцем репозитория. Не помещайте реальные ключи в команды, README, issues или сообщения коммитов. Для сервера используйте [руководство администратора](../services/assistant/DEPLOYMENT_RU.md).
