## Изменения рабочего периода

- Собственная панель Windows с узкими проверенными IPC-командами, подтверждением закрытия несохранённой работы, компактная цветная навигация со сворачиванием и крупный редактор.
- Небольшой плавающий чат с сохранением состояния, возвратом фокуса и закрытием Escape. Согласие на передачу контекста, точный предпросмотр и защита от применения ответа к изменённому коду сохранены.
- Центр уведомлений показывает реальные события сохранения и сборки; положение окна сохраняется. Восстановление после ошибок запуска и renderer не создаёт пустое автосохранение поверх работы.
- Анимации автоматически останавливаются вне видимости, в другом уроке, при сворачивании и reduced motion. Инструменты чтения и локальное аудио доступны компактно.
- Статус компонентов отделён от транспорта платы. Исправлены ошибки IPC, повторное чтение профилей, устаревшие ответы и подтверждение замены драйвера с сохранением схемы до явного применения.
- Импорт подтверждает замену несохранённого проекта. Список проектов содержит даты, поиск и страницы. Масштаб кода меняется встроенными командами Monaco без изменения исходника.
- Все desktop-сборки используют управляемый сервер помощника. Настройка секретов из renderer запрещена. Общий ключ провайдера остаётся на сервере; Windows secure storage хранит только отдельный токен ученика. Сервер подготовлен, публично не развёрнут.
- Обновлены руководство, политика, серверная инструкция, README, Git ignore и проверки архитектуры. Удалена устаревшая форма ключа. Политика объясняет, что полный журнал компилятора может содержать код и локальные пути.
- Production-сборка уменьшила основной app.js с 18 715 203 до 8 490 112 байт. Это измерение размера, а не доказательство общей скорости или экономии памяти.

## До выпуска

Подробные сценарии ручной приёмки: [RELEASE_ACCEPTANCE_RU.md](RELEASE_ACCEPTANCE_RU.md).

1. Проверить Windows 10, чистую установку, обновление, удаление и цифровую подпись. Этот хост — Windows 11 Pro, build 26300; номер Windows_NT 10.0 не означает проверку Windows 10.
2. Развернуть публичный HTTPS-сервер помощника, настроить секреты, выдачу и отзыв токенов, лимиты и мониторинг. Linux/systemd-инструкция подготовлена, реальное развёртывание и платная модель не проверены.
3. После получения спецификаций платы реализовать и проверить физическое подключение, загрузку, моторы и датчики. Набор ещё не существует; симуляция и компиляция не заменяют эти проверки.
4. Провести независимую техническую и языковую вычитку 60 уроков, пользовательские занятия и проверку доступности. 136 EN/RU аудиофайлов совпали по хешам, но человеческая прослушка и казахские записи ещё нужны. Частичная проверка контраста не является сертификацией доступности.
5. Измерить запуск и сборку на школьных компьютерах; оптимизировать повторные проверки SDK без снижения целостности. Один изолированный запуск r5 дал 1950 мс, но под нагрузкой наблюдалось более пяти секунд — общей гарантии нет.
6. Выполнить новый полный UI-прогон после исправлений и проверить подготовленный GitHub Actions на реальном репозитории. Workflow закрепляет action SHA, имеет read-only permissions и не публикует; в GitHub он пока не запускался.
