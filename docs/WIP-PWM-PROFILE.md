# PWM capability and bounded conversion — unpublished groundwork for L15

`resolveIndicatorPWM` resolves the project's actual indicator GPIO through its selected profile and existing wiring validation. It rejects provisional profiles, unassigned indicators and pins lacking output/PWM capability or marked reserved. It returns an explicit proposed indicator configuration (1000 Hz, 8 bits), boot sensitivity and physical verification NOT RUN. This configuration is software groundwork, not a verified physical driver. A pure capability helper permits focused invalid-definition tests without bypassing imported-profile validation.

Duty commands must be finite percentages from 0 through 100. Quantization rounds onto 0 through 2^bits−1 with a separately validated resolution from 1–16 bits; invalid inputs fail instead of being silently clamped. The default eight-bit sweep 0/25/50/75/100 maps to 0/64/128/191/255. Tests verify monotonic bounded sweeps, both built-in reference profiles, wired GPIO selection, boot sensitivity, unassigned/provisional/unsupported pins and invalid numeric inputs. Early test fixtures used a wrong C3 ID and omitted custom profile binding; both fixtures were corrected while preserving validation.

All 155 unit tests pass; package branch coverage is 1081/1164 (92.86%) with unchanged per-file thresholds. Typecheck and lint pass. Blockly PWM blocks, generated C++, simulator brightness and L15 content remain outstanding. No PWM hardware compilation/upload or physical brightness measurement has been performed, and no new installer contains this unpublished work. Authored lesson count remains 14/60.
