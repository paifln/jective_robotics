# Telemetry and log evidence boundaries

New tests verify unknown connection/port provenance and unknown unit annotation remain explicit, raw messages and valid acknowledgement frames do not become measurements, and events outside the latest 1000-event window do not supply a stale connection. Serial export rejects histories above its 1000-record limit.

A new invalid-time test exposed an overly permissive event timestamp schema. Source now requires ISO datetime timestamps, matching the actual desktop receipt timestamps generated by the device service. Invalid records cannot be exported as valid clock evidence. This is a runtime source change after published 0.4.0.

All 70 tests passed. Branch coverage is 100 percent for telemetry collection/export and serial log export, and 647/793 (81.58 percent) overall. The per-file 80 percent gate still fails for five other modules; full coverage acceptance remains incomplete. Type checking, lint and targeted Electron serial-export/telemetry scenarios passed. Injected telemetry test frames are explicit fixtures and do not prove physical serial receipt.
