# L20 motor-test model groundwork

The working tree adds an explicit percentage-duty safety model and separate startup, commanded stop and communication-loss experiments. Each result includes simulation origin, limits, accepted/rejected actions and timestamped outputs. It is not the existing rover velocity model: percentage duty does not establish physical speed or stopping distance.

The model starts disarmed, rejects motion before arming, bounds duty to ±30 and duration to 1–2000 ms, caps acceleration at 40 percentage points/second, holds zero during reversal and expires tethered authority at 400 ms using unsigned timestamp subtraction. Physical-stop input and a latched fault disarm; later heartbeats do not automatically rearm. Autonomous mode requires an explicitly available stop input. These rules mirror the intended pure firmware controller, but cross-language trace comparison remains to be added before claiming parity.

The actual C++ SafetyController header now compiles and executes on the host for the three fixed scenarios. scripts/motor-model-check.mjs compares all accepted/rejected actions and 26 timestamped output/state samples per scenario with the TypeScript model, at a 1e-5 percentage-point numeric tolerance. This establishes parity for those scenarios, not the whole controller, ESP32 scheduling or electrical behavior.

Guide G04 now includes an interactive simulation panel with three independent experiments, a percentage-duty graph, action outcomes and separate JSON exports with simulation origin and physicalVerification NOT RUN. Both channels receive equal commands, so the graph explicitly shows the left channel. The native Electron test checks all three downloaded reports and the 400 ms watchdog transition.

L20 is now registered as a draft EN/KK/RU lesson with 779 learner-facing English words, three explained assessment questions, checked concept/numeric practice, an evidence comparison activity and a four-point rubric. Its interactive panel is available directly in the lesson as well as G04. Curriculum is 20/60; forty lessons and technical translation review remain. No physical motor, port, upload or physical stop test is performed by this model. Published 0.7.0 artifacts remain unchanged. Current lesson proof is under evidence/L20; evidence/motor-model-comparison and evidence/motor-test-model preserve earlier scopes.
