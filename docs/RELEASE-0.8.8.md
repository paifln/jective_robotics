# 0.8.8 — responsive time and bounded collections

This release includes L40 and L41 in English, Russian and Kazakh, bringing the curriculum to **41/60 draft lessons**. Both have substantive theory, worked examples, guided and independent Code tasks, assessment questions, knowledge checks and adaptive persisted exercises. Language review remains required.

L40 replaces blocking waits with elapsed-time states, explains unsigned timer rollover and gives stop requests priority with an explicit restart requirement. Its interactive model compares timelines, counter values and polling latency. L41 keeps the latest eight ordered records, preserves valid zero and distinguishes missing/malformed data. It visualizes indices, overwriting and fault statuses, produces compact JSON and asks learners to repair a logical error that still compiles. The collection exercise uses ordering rather than another numeric question.

Code tasks open directly in Monaco at STUDENT TASK and preserve independently saved projects. Reports distinguish model inputs/answers from execution of edited student source, actual compilation and physical observations. L41 input is manually supplied ADC-count text, not sensor acquisition. It is ordinary student Serial output; tests confirm that the hardware protocol parser does not accept it as a protocol frame. No carrier pin assignment or motor action is added.

Native verification executes the authoritative C++ cores and actual sketches with enabled assertions and explicit clock/Serial substitutes. L40 checks six rollover/stop traces, latching, priority and both sketches' observed stop responsiveness. L41 checks eight input batches, correct indexing/order, fixed memory, zero/missing/malformed distinctions, oversized-token recovery and the starter defect. Adjacent checks cover 16/17-character tokens and exact/one-byte-short output capacity. Both starter/reference sketches for each lesson compile with the actual ESP32 toolchain. This does not verify physical sampling or stop timing.

The full domain suite passes **348 tests across 114 files**; branch coverage is **96.24%**, with the unchanged per-file 80% gate. TypeScript, lint and build pass. Four targeted source Electron scenarios pass together with no failures, skips or flakes: both new lessons, all 41 introductions/themes/animation/editor/simulator, and the actual board-wizard compiler success/error/stale-upload flow. The L41 test also verifies real file preservation, report download contents and all three languages. The earlier failed selector run is retained separately. Source screenshots were visually inspected; light-theme diagram text contrast was corrected and the scenario rerun.

Dependency audit reports zero known vulnerabilities. Packaged Windows 11 startup, single-instance rejection, binary fuses, exact tested-build equality and intentional ASAR tamper rejection pass. The archive was restored and its original hash verified. This is a packaged startup/security smoke check, not installation/uninstallation or a full packaged UI suite.
