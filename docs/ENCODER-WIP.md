Published 0.8.1 archives remain unchanged at 23 lessons; this source increment is unpackaged.

The transport-neutral adapter accepts unsigned 16/32-bit raw counts, increasing sample time and reset epoch. First samples establish a baseline. Subsequent signed modular differences assume less than half-range movement and a declared maximum change per sample. Half-range and excessive changes reject without replacing the accepted baseline. Reset epochs start new distance segments, rather than inventing reverse travel. Decoded counts per wheel revolution explicitly include quadrature and gearing assumptions, and distance uses circumference in metres.

The x4 quadrature decoder defines 00 → 01 → 11 → 10 → 00 as positive, reverse as negative, and repeated levels as zero. Skipped two-bit transitions latch a fault until explicit reset to known levels. Both counter widths compose with the unsigned-count adapter through its existing snapshot interface. This is a software interface and declared signal model; physical interrupt/serial pulse acquisition is not implemented or verified by this lesson.

Actual RobotSimulation motion runs forward, settles, reverses and settles. Integrating modeled wheel velocities at 20 ms then quantizing travel produces simulated count snapshots. Each decoded estimate differs from integrated travel by less than one count's distance. The separate no-encoder alternative assumes nominal speed 0.6 m/s and durations. At modeled maximum speed 0.5 m/s the measured model travel disagrees with that fixed estimate; it is not fake disconnected-sensor telemetry. The calculation artifacts use declared 180/360/−90 counts; starter scaling 200 is deliberately incorrect, reference scaling 360 produces 0.10/0.20/−0.05 m.
