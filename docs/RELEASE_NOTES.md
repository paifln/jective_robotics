# Изменения проекта

## Текущие исходники — 16 октября 2026, ещё не релиз

- Ограничены чтение файлов, фактическая распаковка ZIP и ресурсы Blockly; добавлены строгий UTF-8, согласованность заголовков ZIP и CRC. Подготовка открытия отделена от принятия проекта после проверки редактора.
- Сохранение использует уникальный эксклюзивный временный файл. Исправлено открытие локального проекта во время сохранения предыдущего без подмены новой работы поздним ответом.
- Зашифрованный ученический токен привязан к адресу сервера. Старые записи требуют повторной настройки; секретные переменные удаляются из окружения main до обычного запуска.
- Потоковая проверка и копирование инструментов, проверка Windows-путей, точный манифест согласия и нативное подтверждение перед импортом исполняемых инструментов.
- Подготовлены отдельный Docker для Railway, постоянные квоты, сброс root-прав и Windows-мастер со скрытым вводом ключа вне Git. Сервер фактически развёрнут; внешние HTTPS-проверки здоровья, авторизации и cross-origin границы прошли без оплачиваемого запроса OpenAI.
- Помощник получил имя Jexi, оформление мессенджера и локального объёмного персонажа с анимацией, приостанавливаемой при скрытии. Enter отправляет, Shift+Enter переносит строку. [Отдельные проверки и ограничения новой сборки](../evidence/jexi-20261016/verification.md).
- Добавлены Linux CI-проверка контейнера и еженедельные Dependabot-запросы обновлений npm, Actions и базового Docker-образа. Удалённые проверки пока не запускались.

В сохранённом снимке r6 до добавления Jexi прошли 616 доменных тестов и 132 выбранных GUI-сценария. 19 текущих серверных тестов прошли; после Jexi отдельно прошли 11 клиентских тестов, 4 UI-сценария и проверка нового EXE с локальным тестовым gateway. Контрольный пакет security r3 прошёл UI/compile/restart и сканирование Defender без обнаруженных угроз. Цикл compile занял 374169 мс — это не готовый целевой результат. Windows 10, подпись и полный цикл установщика, реальный ответ модели и аппаратная проверка остаются открытыми. [Точные свидетельства](../evidence/security-hardening-20261016/verification.md).

## Текущие исходники — 15 октября 2026, ещё не релиз

Версия пакета остаётся 0.8.18. Исходники и отдельные проверочные сборки обновляются после этой версии; существующий установщик в каталоге release не следует считать автоматически обновлённым.

- Собственная панель окна Windows, сворачиваемая навигация, цветные значки, компактный плавающий помощник и уведомления о реальном сохранении и проверке кода.
- Мотивация на синей заставке с белым логотипом. 59 разных записей на трёх языках: 9 коротких цитат с источниками и 50 фраз JECTIVE. Приветствие по времени суток из уроков убрано.
- Удобнее чтение уроков и кода: небольшие кнопки озвучивания и параметров текста, отдельное увеличение шрифта Monaco; иллюстрации автоматически останавливаются вне видимой области.
- Сохранение и восстановление работ, подтверждение перед импортом поверх несохранённых изменений, понятные сообщения об ошибках портов и обновление списка профилей без выхода из студии.
- Серверный помощник с индивидуальными токенами учеников. Общий ключ провайдера остаётся на сервере; настройки ключа и модели недоступны ученикам.
- Обновлены сценарии проверки интерфейса под текущую навигацию. Удалённые административные элементы не возвращались ради старых тестов.

580 доменных тестов прошли; первый полный UI-прогон завершился с ошибками, второй завершён с результатом 147 прошли, 7 не прошли, 2 пропущены. Результаты отдельных исправленных сценариев не заменяют полный прогон. Точные области проверок и ограничения: [проверки](VERIFICATION.md), [мотивация и источники](LAUNCH_MOTIVATION.md).

Ни создание EXE, ни компиляция справочного проекта не подтверждают готовность к продажам. Физический набор ещё разрабатывается; Windows 10, полный цикл установки, независимая экспертиза уроков и публичный сервер требуют отдельной проверки.
